# Инструкция по настройке WordPress для Art House

## Шаг 1: Настройка базы данных в MAMP

1. Откройте MAMP
2. Запустите серверы (Apache и MySQL)
3. Откройте phpMyAdmin (http://localhost:8888/phpMyAdmin/)
4. Создайте базу данных:
   - Имя: `arthouse_wp`
   - Кодировка: `utf8mb4_unicode_ci`
5. Импортируйте файл `setup-database.sql` (опционально, для примера данных)

## Шаг 2: Настройка WordPress

1. Откройте браузер и перейдите по адресу:
   `http://localhost:8888/art-house-group/wordpress-admin/wordpress/`

2. Следуйте инструкциям установки WordPress:
   - Выберите язык: Русский
   - Заполните данные:
     - Название сайта: Art House Admin
     - Имя пользователя: admin
     - Пароль: (создайте надежный пароль)
     - Email: ваш email

## Шаг 3: Активация плагина и настройка дополнительных полей

1. После установки войдите в админку WordPress
2. Перейдите в "Плагины" → "Установленные"
3. Найдите "Art House Products" и активируйте его
4. В левом меню появится пункт "Продукты"
5. Скопируйте файл `custom-fields.php` в папку `wordpress/wp-content/mu-plugins/`
6. Создайте папку `mu-plugins` если её нет

## Шаг 4: Добавление продуктов

1. Перейдите в "Продукты" → "Добавить продукт"
2. Заполните поля:
   - Заголовок: название продукта
   - Описание: подробное описание
   - Изображение записи: загрузите изображение
   - В блоке "Детали продукта" заполните:
     - Цена ($)
     - Площадь (м²)
     - Вместимость
     - Мощность (кВт)
     - Размеры (м)
     - Вес (тонны)
   - В блоке "Дополнительные системы" заполните:
     - Внешняя система защиты (через символ |)
     - Система гостевого контроля (через символ |)
     - Аксессуары для продукта (через символ |)

## Шаг 5: Интеграция с фронтендом

1. Скопируйте файл `api-integration.js` в папку с вашим сайтом
2. Добавьте в `index.html` перед закрывающим тегом `</body>`:
   ```html
   <script src="./wordpress-admin/api-integration.js"></script>
   ```

## Шаг 6: Проверка работы

1. Откройте ваш сайт: `http://localhost:8888/art-house-group/`
2. Перейдите в раздел "Каталог"
3. Продукты должны загружаться автоматически из WordPress

## API Endpoints

- Получить все продукты: `http://localhost:8888/art-house-group/wordpress-admin/wordpress/wp-json/arthouse/v1/products`
- Получить один продукт: `http://localhost:8888/art-house-group/wordpress-admin/wordpress/wp-json/arthouse/v1/products/{id}`

## Устранение проблем

### Если продукты не загружаются:
1. Проверьте, что MAMP запущен
2. Проверьте, что база данных создана
3. Проверьте консоль браузера на ошибки
4. Убедитесь, что плагин активирован

### Если CORS ошибки:
1. Убедитесь, что файл `arthouse-setup.php` находится в папке `mu-plugins`
2. Проверьте настройки CORS в плагине

### Если API не отвечает:
1. Проверьте URL в `api-integration.js`
2. Убедитесь, что WordPress установлен правильно
3. Проверьте права доступа к файлам

## Структура файлов

```
wordpress-admin/
├── wordpress/                    # WordPress core
│   └── wp-content/
│       └── mu-plugins/
│           └── custom-fields.php # Дополнительные поля для продуктов
├── api-integration.js            # Интеграция с фронтендом
├── custom-fields.php             # Файл для копирования в mu-plugins
├── get-products.php              # API для получения продуктов
├── setup-database.sql           # SQL для настройки БД
└── SETUP_INSTRUCTIONS.md        # Эта инструкция
```

## Дополнительные настройки

### Изменение URL API
Если ваш WordPress установлен по другому пути, измените в `api-integration.js`:
```javascript
this.apiUrl = 'http://localhost:8888/ваш-путь/wp-json/arthouse/v1';
```

### Настройка портов MAMP
Если MAMP работает на других портах, измените в `wp-config.php`:
```php
define( 'DB_HOST', 'localhost:ваш-порт' );
```
